# Schema Checks

Valida salud y colecciones requeridas:

```powershell
node scripts/pb-check.mjs
```

Variables:

- `PB_URL`
- `PB_ADMIN_EMAIL`
- `PB_ADMIN_PASSWORD`

Colecciones verificadas:

- `points`
- `shipments`
- `partner_applications`
- `users`
- `system_settings`
- `commissions`
- `invoices`
